# 内置 Agent 消息 inbox

运行期间仍可输入文字、添加附件和发送消息。消息先持久化到当前会话 SQLite 的 `inbox_json`，不提前混入模型上下文。

- **待发队列（queue）**：当前任务的模型回复不再包含工具调用后，依次取出一条继续处理。
- **调整方向（steer）**：优先于 queue，在下一次模型调用前取出；不会强制取消模型请求或正在执行的工具批次，保持 tool-call/result 协议完整。
- 前端参考 OpenCode v2 `session/composer/queue-panel.tsx`：待发队列贴附在输入框上方，单行摘要、附件计数、超过三条显示总数、超过四条滚动。触屏操作始终可见，拖拽手柄长按排序。
- 点击消息在主输入框编辑（原草稿暂存，保存或取消后恢复），可修改文字和附件；行尾提供“调整方向/发送”、撤回到输入框、删除。发送模式使用紧凑下拉菜单，不使用大按钮或编辑弹窗。
- 投递时在一个数据库事务中删除 inbox 项、结束旧回复并追加用户消息和新回复占位。模型上下文使用用户消息 ID，后续输出关联新回复 ID。
- 停止或失败不会清空待发消息，可通过“继续处理待发消息”恢复。进程异常中断后保留待发项，不自动重放可能产生副作用的任务。
- 数据库 schema 4 为已有会话增加 inbox 字段，旧会话默认空列表。

OpenCode v2 参考契约：https://opencode.ai/v2/docs/api （`Session.Inbox.Delivery` 的 `queue` / `steer`）。这是内置 Kotlin agent 的对应交互，并非接入 OpenCode 服务。
